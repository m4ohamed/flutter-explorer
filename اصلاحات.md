### 4️⃣ تجاهل التوجيهات (Directives: Imports & Exports)

الكود الحالي يبدأ التحليل مباشرة من:
```dart
for (final declaration in unit.declarations)
```
ويتجاهل تماماً:
```dart
for (final directive in unit.directives) // ImportDirective & ExportDirective
```
مما جعل حقول `imports` و `exports` فارغة دائماً، وبالتالي يفقد المحلل القدرة على رسم خريطة الاعتماديات العكسية (Reverse Dependencies) واعتماديات الرسم البياني الدقيق.

## 🛠️ كود الترقية المعتمد لـ [dart_analyzer.dart](file:///c:/Users/m4oha/OneDrive/Desktop/new/tools/dart_analyzer.dart)

لترقية المحلل وتصحيح الخلل بالكامل وتحقيق التوافق التام مع واجهة [DartFileInfo](file:///c:/Users/m4oha/OneDrive/Desktop/new/src/indexer/dartParser.ts#L203-L233) في TypeScript، هذا هو الهيكل البرمجي المنقّح والمصحح:

```dart
// 1. استخراج الـ Directives (Imports & Exports)
final imports = <Map<String, dynamic>>[];
final exports = <String>[];

for (final directive in unit.directives) {
  if (directive is ImportDirective) {
    final showNames = <String>[];
    final hideNames = <String>[];
    for (final combinator in directive.combinators) {
      if (combinator is ShowCombinator) {
        showNames.addAll(combinator.shownNames.map((id) => id.name));
      } else if (combinator is HideCombinator) {
        hideNames.addAll(combinator.hiddenNames.map((id) => id.name));
      }
    }
    imports.add({
      'path': directive.uri.stringValue ?? '',
      'alias': directive.prefix?.name,
      'showNames': showNames,
      'hideNames': hideNames,
      'line': lineInfo.getLocation(directive.offset).lineNumber,
    });
  } else if (directive is ExportDirective) {
    exports.add(directive.uri.stringValue ?? '');
  }
}

// 2. استخراج المشيدات (Constructors) وربطها بالكلاس وبالملف
for (final ctor in clazz.constructors) {
  if (ctor.isSynthetic) continue; // استبعاد المشيد الافتراضي الوهمي
  final ctorName = ctor.name.isEmpty ? clazz.name : '${clazz.name}.${ctor.name}';
  final ctorData = {
    'name': ctorName,
    'className': clazz.name,
    'isFactory': ctor.isFactory,
    'isConst': ctor.isConst,
    'params': ctor.parameters.map((p) => p.getDisplayString(withNullability: true)).join(', '),
    'line': lineInfo.getLocation(ctor.nameOffset != -1 ? ctor.nameOffset : ctor.offset).lineNumber,
  };
  (fileInfo['constructors'] as List).add(ctorData);
}

// 3. دمج الخصائص في مستوى الملف (File-Level Properties)
for (final prop in props) {
  prop['className'] = clazz.name;
  (fileInfo['properties'] as List).add(prop);
}

// 4. استخراج الوسوم (Annotations)
for (final ann in declaration.metadata) {
  (fileInfo['annotations'] as List).add({
    'name': ann.name.name,
    'target': 'class',
    'targetName': clazz.name,
    'line': lineInfo.getLocation(ann.offset).lineNumber,
  });
}
```
